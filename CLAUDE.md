```
Gerçek Kuzey Spor Kulübü için modern, profesyonel ve mobil uyumlu bir web sitesi
tasarla ve kodla.
```

```
Site amatör spor kulübü için olacak. Tasarım resmi, sade, güvenilir ve sportif
görünmeli. Renk teması lacivert ve beyaz olacak. Gerektiği yerlerde açık gri
tonları ve küçük vurgular kullanılabilir ama ana kimlik lacivert-beyaz kalmalı.
```

```
Kulüp adı:
Gerçek Kuzey Spor Kulübü
```

```
Renk teması:
```

```
- Ana renk: Lacivert
```

```
- İkincil renk: Beyaz
```

```
- Destek renk: Açık gri
```

```
- Vurgu olarak çok az altın/sarı kullanılabilir, ama baskın olmamalı.
```

```
Logo:
Yukarıdaki kulüp logosu sitede uygun bir yerde kullanılacak.
Logoyu özellikle navbar alanında ve hero bölümünde kullan.
Eğer logo dosyası projede mevcutsa onu kullan.
Logo yoksa geçici olarak `/logo.png` path’i ile placeholder bırak.
```
